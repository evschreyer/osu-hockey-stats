Player embed codes

Every player on the current ACHA roster gets a ready-to-paste code. The list reads the live roster, so new players show up here automatically.

  1. Host the osu-hockey-stats folder (GitHub Pages or Cloudflare Pages) and paste its address below.
  2. In GoDaddy, open a player's profile page → Add Section → HTML → paste that player's code.
  3. For a team page, paste the whole-roster code instead. Tapping a player opens their stats inside the same box.
